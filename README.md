# Calculadora
calculadora python usando o shell como exe

# Arquivo .sh
Ele é o responsável para fazer a calculadora funcionar.
Para utilizar este arquivo é necessário ter um Terminal de preferencia Linux para executar o ShellScript.

# Arquivo .py
Ele irá operar a calculadora após o uso do arquivo SH ser utilizado.
Com uma interface simples e direta para o uso.
Caso tenha dúvidas siga estas instruções logo abaixo!

* Selecione as opções entre 1 - 4.
* Escolha o Primeiro e Segundo número que será utilizado com base na opção selecionada.
* Irá sair o resultado do calculo logo após efetuar sua equação desejada.
* Caso queira fechar a calculadora, basta selecionar a opção 5 que irá ser finalizada.
